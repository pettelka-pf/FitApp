# FitApp

A JavaFX-based fitness desktop application for tracking workouts, calories, and training plans.

## Features:
- User login and registration
- Caloric intake tracker
- Exercise management (Weight, Cardio Running, Cardio Calisthenics)
- Training plan creation
- Statistics overview

## Tech Stack:
- Java 21
- JavaFX 21
- PostgreSQL (Neon Cloud)
- Maven

## Setup: 
1. Clone the repository:
   git clone https://github.com/pettelkr/FitApp.git

2. Create a `.env` file in the root folder:
   DB_URL=your_neon_url
   DB_USER=your_user
   DB_PASSWORD=your_password

3. Run the app:
   mvn javafx:run
